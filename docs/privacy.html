시행일: {{시행일}} · 운영자: {{운영자 이름}}

{{운영자 이름}}(이하 "운영자")은 모바일 게임 "신화 블록"(이하 "게임")을 이용하는 분의 개인정보를 소중히 다룹니다.

1. 수집하는 정보

회원가입이나 로그인은 없습니다. 이름·이메일·전화번호·위치·연락처·사진에는 접근하지 않습니다.

주간 랭킹에 참여할 때만 아래 정보를 저장합니다.

  • 앱이 자동으로 만드는 익명 식별번호(개인을 알아볼 수 없는 무작위 값)
  • 이용자가 정한 닉네임
  • 점수, 도달 단계, 기록 시각, 플레이한 수·시간(부정 기록을 막는 확인용)

랭킹에 참여하지 않으면 서버로 아무 정보도 보내지 않습니다.

2. 이용 목적과 보관 기간

랭킹을 보여주고 부정 기록을 막는 데만 씁니다. 닉네임과 점수는 랭킹 화면에서 다른 이용자에게 공개됩니다. 이용자가 삭제할 때까지 보관하며, 게임 안 설정 → 랭킹 기록 삭제를 누르면 닉네임과 모든 랭킹 기록이 즉시 지워집니다.

3. 기기에 저장되는 정보

최고 점수, 영웅 도감, 동행 영웅 같은 게임 기록은 이용자의 기기 안에만 저장되며 운영자에게 전송되지 않습니다. 앱을 지우거나 브라우저 데이터를 지우면 함께 삭제됩니다.

4. 처리 위탁 및 제3자 제공

랭킹 정보는 Supabase(서버 위치: 대한민국 서울)에 저장합니다. 광고·분석·결제 서비스는 사용하지 않으며, 정보를 제3자에게 팔거나 제공하지 않습니다. 앞으로 광고나 분석 도구를 넣게 되면 이 방침을 먼저 고치고 앱 안에 알리겠습니다.

5. 아동의 개인정보

랭킹 닉네임에는 실명이나 연락처 같은 개인정보를 쓰지 말아 주세요. 운영자는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.
